# Хмарний голосовий помічник

Навчальний проєкт для автоматизації обліку постачальників, товарів і поставок за допомогою вебінтерфейсу, Telegram-бота та голосових команд.

## Поточна архітектура

- **FastAPI** — єдиний серверний застосунок і REST API.
- **PostgreSQL** — основна база даних.
- **SQLAlchemy** — робота з таблицями та зв'язками.
- **Вебінтерфейс** — україномовна панель для ведення довідників і реєстрації поставок.
- **Telegram** — буде підключений до тих самих серверних операцій, щоб дані не дублювалися.
- **Голосові функції** — наступний етап: завантаження аудіо, розпізнавання українського мовлення та синтез відповіді.

## Структура

```text
backend/
  api/routes.py          REST-операції
  database/               моделі, підключення та схема БД
  config.py               налаштування через змінні середовища
  main.py                 точка запуску FastAPI
frontend/
  index.html              вебсторінка
  style.css               оформлення
  app.js                  взаємодія з API
tests/
  test_api.py             автоматизовані тести API
```

## Локальний запуск у Windows

Потрібні Python 3.11 або новіший та встановлений PostgreSQL.

1. Клонувати репозиторій і перейти в його каталог.
2. Створити віртуальне середовище:

   ```powershell
   py -m venv .venv
   .venv\Scripts\activate
   ```

3. Встановити залежності:

   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. Створити в PostgreSQL базу даних з назвою `voice_assistant`.
5. Скопіювати `.env.example` у `.env` і вказати пароль та адресу бази даних у `DATABASE_URL`.
6. Створити таблиці:

   ```powershell
   python -m backend.database.init_db
   ```

7. Запустити сервер із кореня репозиторію:

   ```powershell
   uvicorn backend.main:app --reload
   ```

8. Відкрити:
   - Вебінтерфейс: http://127.0.0.1:8000/
   - Документація API: http://127.0.0.1:8000/docs
   - Перевірка стану: http://127.0.0.1:8000/health

## Основні API-операції

| Метод | Шлях | Призначення |
|---|---|---|
| GET, POST | `/api/suppliers` | Перегляд і створення постачальників |
| GET, PUT, DELETE | `/api/suppliers/{id}` | Отримання, редагування та видалення постачальника |
| GET, POST | `/api/products` | Перегляд і створення товарів |
| PUT, DELETE | `/api/products/{id}` | Редагування та видалення товару |
| GET, POST | `/api/deliveries` | Перегляд і реєстрація поставок |
| PUT, DELETE | `/api/deliveries/{id}` | Редагування та видалення поставки |
| GET | `/api/deliveries/export.csv` | Експорт поставок у CSV |

## Тестування

Після встановлення залежностей виконати:

```powershell
pytest -q
```

Тести використовують тимчасову SQLite-базу, тому для їх запуску не потрібно підключатися до робочої PostgreSQL.

## Безпека

Не зберігайте реальні токени, паролі чи ключі API в репозиторії. Для локального запуску використовуйте файл `.env`, який не додається до Git. Раніше опубліковані ключі OpenRouter і токен Telegram потрібно відкликати та створити нові до розгортання проєкту.

## Стан реалізації

На поточному етапі реалізовано початкову схему даних, CRUD API для основних сутностей, CSV-експорт і базовий вебінтерфейс. Інтеграція Telegram, голосове введення/виведення, автентифікація, міграції Alembic, хмарне розгортання та вимірювання продуктивності ще потребують реалізації й перевірки.
